# 科贝拉流浪者

以《卓越之剑》（Granado Espada）世界为背景的中文同人长篇小说。

海难之后，莱斯来到科贝拉。他带着相互交织的记忆，在陌生大陆上找住处、学着谋生，与同伴走进群山和古城。远行带来见闻、财富与失去，也让人逐渐有了想回去的地方。故事关心冒险之后仍要继续的生活，以及人在能够离开时，怎样决定自己的去留。
