# 文脉 Wenmai

**面向中文长篇小说的创作与审修 Skill。** 从人物愿望和具体经历出发，贯通故事推进、场面组织与文字表达，并用准确的作品状态接续长任务。

当前版本：**0.8.0-dev.15 · 开发版**。调用名：`$longform-fiction`。

[快速开始](#快速开始) · [调用示例](#调用示例) · [按任务加载](#按任务加载) · [版本与验证](#版本与验证) · [完整方法目录](longform-fiction/README.md#按任务读取)

## 可以用来做什么

| 工作 | 关注什么 |
|---|---|
| 作品构想与人物设计 | 找到值得展开的生活、具体愿望和真正不同的故事方向 |
| 正文与场面写作 | 让心理、行动、对白和相处形成连续经历，保有人物声口 |
| 审读与精修 | 分开判断内容准确、阅读顺畅与文学效果，比较修改的收益和损失 |
| 分卷与长篇组织 | 让前面的获得、失去和选择改变后续经历，检查连读疲倦与重复 |
| 续写与中断恢复 | 找到准确采用稿、人物知情、未决事项和实际完成范围 |
| 按需协作 | 交接必要原文与方法，区分执笔、独立首次阅读和主编采用 |

文脉保留直接心理、口语、误会、笨拙、日常欲望与快乐的表达空间。修订依据具体语境和读感；不会把每章统一写成短句、冲突、金句或悬念。

## 快速开始

### 方式一：下载离线包

下载 [wenmai-fiction-v0.8.0-dev.15.zip](releases/v0.8.0-dev.15/wenmai-fiction-v0.8.0-dev.15.zip?raw=true)，可对照 [SHA256SUMS.txt](releases/v0.8.0-dev.15/SHA256SUMS.txt) 校验。

解压后得到 `Install.ps1`、`manifest.json` 和完整的 `longform-fiction/`。在解压目录运行以下命令，将路径改为**已经存在的小说项目目录**：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -ProjectPath 'D:\MyNovel'
```

安装器使用 Windows PowerShell 5.1 或以上，校验包内文件并拒绝覆盖已有同名 Skill；安装过程无需 Python。请在独立解压目录运行安装器，保留原包结构。

### 方式二：复制完整 Skill 目录

克隆或下载本仓库，将 **`skills/wenmai/longform-fiction/` 整个目录**复制到你自己的小说项目的 `.agents/skills/` 下，形成：

```text
你的小说项目/
└─ .agents/
   └─ skills/
      └─ longform-fiction/
         ├─ SKILL.md
         ├─ README.md
         ├─ agents/
         ├─ references/
         └─ scripts/
```

保留全部参考文件；只复制 `SKILL.md` 会丢失方法。若目标已有同名目录，先保留旧版，再明确更新。

在 Codex 中可以通过 `$longform-fiction` 显式调用；技能未出现时重启 Codex。项目目录与调用规则见 [OpenAI 官方技能说明](https://learn.chatgpt.com/docs/build-skills)。其他宿主可按自身规则加载完整目录，本版没有对所有宿主逐一验证。

## 调用示例

在项目中提供当前采用正文、必要前文和明确目标，然后提出任务。

**单章精修：**

```text
$longform-fiction
精修 chapters/012.md。先连续读完整章，再判断哪里需要改、哪里应保留。
保护有效的直接心理、口语和日常快乐，不改人物关系与已发生事实。
另存候选并完整复读，简述修改收益、损失和未决问题。
```

**独立首次阅读：**

```text
$longform-fiction
按中性首读入口连续读指定三章。先保存实际阅读反应，
再解释哪里投入、哪里走神、读完记住什么。
首次意见保存前不读旧评语或写作者自评；记录实际背景暴露和已读版本。
```

**长任务接续：**

```text
$longform-fiction
根据项目当前入口恢复本轮修订。先核采用稿、读程与真实任务状态，
找出下一步；入口里的旧数量不能代替实际记录，不重派已有任务。
```

普通写作可以由一个主写持续推进；需要独立判断或作者明确要求时再分工。使用独立首读，应提供必要的中性背景；同一上下文换角色名不算独立评阅。

## 按任务加载

[SKILL.md](longform-fiction/SKILL.md) 提供常见任务入口，[Skill README](longform-fiction/README.md) 提供专题目录与工具说明。安装完整目录不等于每次全部读取。

- 普通执笔和编辑直接进入当前原文与相关方法，已有且未变的材料不重复加载。
- 需要恢复项目经验时，训练 JSON 首次只输出结构，再取当前相关字段与指针；选中的方法须连同条件、例子和误用边界读取。
- 审题、段句索引、批量派收及生命周期契约，只在相应任务触发时展开。
- 减载保留必要前文、完整源章和本次要求的复读；方法经验与故事事实分别取用。

两项可选脚本提供机械核验，均使用 Python 3.10 或以上及标准库；普通写作、手动安装和离线安装不依赖它们：

| 工具 | 用途 |
|---|---|
| [revision_index.py](longform-fiction/scripts/revision_index.py) | 段句定位、文本版本与覆盖声明核验 |
| [batch_revision.py](longform-fiction/scripts/batch_revision.py) | 批量任务、交付版本及显式宿主回收契约核验 |

脚本通过说明记录与文本相符；文学判断仍需要实际读稿。

## 版本与验证

dev.15 完成按任务加载调优、去项目化与来源定位清理；随包保留七条可迁移经验及其适用边界。包内不附具体作品的正文、人物档案、预研原书或项目阅读进度。

本轮验收包括23项迁移／发布检查、离线包独立校验、全新项目安装与拒绝覆盖，以及新上下文的短原创样稿应用和路由复核。详情见 [版本验证说明](docs/validation-v0.8.0-dev.15.md)。

主入口在固定 `o200k_base` 编码下由1,860降至958参考 token，减少约48.5%。这是方法文本量，实际任务还要计入正文、工具、输出、缓存、重试和项目指令；没有测量实际费用或承诺相同降幅。

当前方法来自有限阅读观察、原创练习、模型审读和真实取得的反馈。短场面应用与工程检查不构成长篇文学质量认证，也不保证每个模型、题材或会话都有同样效果。保存经验文件也不会修改模型参数；跨会话能力依赖材料被正确找到、读取和应用。
