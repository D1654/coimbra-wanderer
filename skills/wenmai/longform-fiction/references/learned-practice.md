# 当前可迁移经验

以下是来自公开作品阅读观察与原创场面局部应用的工作判断，不是文学定律。编号和修订标识用于选取当前判断；详细训练履历与反馈原件由维护者另存，不随Skill迁移。各岗位均可使用，按眼前问题选取，不要求每章逐项打勾，也不能因读过经验就声称读完来源作品。

## WM-01 / r2：让具体愿望与惯常反应相遇

人物想要某种具体生活体验，往往比抽象的“自由”“成长”更易使人关心。保留使这个愿望难以实现的小气、好胜、顾虑或笨拙；心理可以直接写，不能全换成手势。适用于人物清楚却缺乏个人吸引力时。一个愿望加一个缺点仍可能工整可预见，别当人物生成公式。

r2补充：判断一个连续经历中是否仍能跟上人物的在意之处，不能因偶有心理句便认为体验已充分，也不逐段补念头。深层来源未决与当下感受可辨可以并存，具体边界见[创作与表达](craft.md)。

来源：原创生活场面的局部应用。对单篇的判断不能推及整部长篇，也不能当作作者逐条确认。

## WM-02 / r1：一次变化有范围，也有后续

一次受助、和解或成功，不会自动取消人物其他需求。记录这一次选择及影响，继续写原习惯怎样与新局面共存；对方也有自己的生活。可用于避免每章人物归零或一次顿悟永久解决。不要故意让所有改变都失败。

来源：原创关系场面的局部应用。尚无完整长篇验证。

## WM-03 / r2：确认哪件事，就更新哪件事

亲见、听说、推断、梦境与承诺不能一并记作事实；后来的证据也可以提高其中某项的可信度。读者看过不等于每个人都知道，计划完成不等于事情完成。用途是正确承接行动，不是让正文写证据清单。

辨别边界：不能把这一判断误用成“梦里听到的话永远不能采信”。后来若有现实中的新证据印证其中一项，可以提高该项的可信度；仍不能据此确认整段陈述。

原创辨别例：一个人发誓下月回城，可以记其说过的承诺，不能记他已回城。另一个人后来亲见他进城，可以更新到达事实，不能顺便认定他履行了其余承诺。

## WM-04 / r1：省略是否有效，取决于它改变什么

普通走路、开门、递物可自然省略；关键的承重、位置、对象、收到的信息若决定结果，就需成立。对白回避也可能是回应，看对方实际问了什么，不按章纲替人补话。不要将“具体”写成逐帧操作，也不要以留白宽免关键因果断裂。

来源：原创场面的局部修订与模型审读。适用的是会改变理解的必要因果，不是所有日常动作。

## WM-05 / r3：能看懂之后，还要愿意关心

记录何处投入、何处走神，再找正文原因。笑话可以建立亲密，也会让被戏弄者显得被轻视；安静结尾可以留下责任，不必每次突发危险。是否幽默、是否激烈都不是统一指标。

r2补充：清楚、可亲、愿意停留与迫切追读分开判断。连续确认与安顿若挤掉人物的在意之处，可以调整场面和详略；不能因减少说明而删掉有效的失落、私心或心理过程，也不把办事场面一律改成争吵。按需读[让经历值得读](reader-engagement.md)。更有生活气与更牵动人物可能不是同一稿的长处。

r3应用取向：识别两稿不同所长之后，应把它们为何成立转成同一套场面判断，而不止并列保留。让人物感受贯穿相处，生活中的回应影响他的理解或选择；复读时检查增强一种体验有没有无故削弱另一种。它不要求每场按比例分配内心与笑话，也不以拼接旧稿段落证明融合。融合效果仍须看实际产物，不能把方法方向当作实测结论。

来源：原创场面的局部比较。已有比较呈现不同稿各有收益，没有证明方法普遍更优；输入背景、熟悉和顺序效应会限制结论，模型意见也不能代替真人反馈或全长篇追读验证。

## WM-06 / r2：修改要改善体验，不能只显得合规

先看前文是否已使含义成立，再决定补解释。直接心理可以重要，重复归纳却可能提早替读者作结论。主编可拒绝审读建议，说明保留什么及其成本；无新问题时结束该轮。

r2补充：同一材料再次出现是否重复，要看它有没有进入新的愿望、争执或选择；心理修订既可增补，也可删去重复清点与自我归纳。用连读检验，而非按词语出现次数删改。

来源：原创场面的局部修订与模型审读。它不规定每章只能改一句，也不豁免需要重构的正文。

## WM-07 / r1：让前章的获得改变后章的经历

跨章连读时，区分事情还没解决与经历毫无进展。较早的等待需要得到实际经历；已经获得的东西可以保留，让它改变接下来的选择。若连续几章都靠相似的谈判、救险或分账收尾，状态再准确也可能疲倦。换事件名称不能代替新的体验；不为制造差异而惩罚每次成功。组织阶段时按需读[长篇的阶段推进](long-arc.md)。

来源：原创连续单元的局部应用。这只支持局部组织判断，没有全长篇或未训练对照证明。

## 证据范围

公开作品观察、原创应用、模型审读和作者反馈是不同依据。上述来源摘要不能代替实际阅读记录，也不能使新岗位继承他人的阅读经历；具体反馈只有在真实取得并有相应范围时才可引用。

局部改稿、连读或比较的结果只支持其实际材料。方法解释、适用边界的修订和新的前瞻应用分别记录，后来的说明不能倒写成较早产物已使用；没有新实测就不宣称新增验证或作者认可，也不把某部作品的身份机制与人物事实变成通则。
