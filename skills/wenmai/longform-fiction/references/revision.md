# 审读与修订

先确定所读稿件版本、作者目标及本次范围，区分内容校核、文学效果和改稿比较；格式、事实或衔接检查不能代替文学判断。需要逐段查漏、分批交接或反复变稿时，按需读[逐段审修与定位](close-revision.md)；普通句段修改无需建立整套索引。审读整书时结合结构摘要与相关原文；检查普通衔接和较早人物回归，不只看最精彩选段。 需要实际组织完卷或整书收口时，按[长篇尺度审读](whole-work-review.md)核阅读覆盖与远近变化；新编辑仍易误修时，可用[完整场面校准](editor-calibration.md)，不把例子结论预载给独立首读。

## 先作为读者读正文

独立首次文学或可读性审读按[中性首读入口](independent-reading.md)，先看指定版本正文和作者目标，不先恢复训练经验或旧意见；事实核查仍可随后按需查资料。用简短复述确认谁在什么处境、如何行动和回应、事情改变了什么。区分原文明示、合理推知及审读者自行补写；“我能替作者编一个解释”不能作为通过依据。

有省略不等于有错误。若日常动作已可自然推知，不因缺一个开门或跨步动词强制扩写；若关键承重、对象或应答关系会因此改变，就给出缺失造成的实际后果。人物说法和指控不是自动成立的事实。诊断时同时保留有效的简省，不为凑问题数改稿。

## 文学效果审读

用于作者问文学效果、人物吸引力、语言读感或场面是否值得保留。完整读一段经历后，先保存当时记住了什么、哪里投入或抽离、还想经历什么，再诊断原因。独立首读不先拿下列观察方向寻找规定症状；编辑已经见过旧意见时，诚实区分复核与首次反应。内容无误可以与文学乏力同时成立，不能只修错句便交付“文学通过”。

理解之后再判断是否愿意继续。可从以下方向追问具体效果，按本场实际作用选择，不逐项评分、不要求每章配齐；独处不必加伙伴，平静不必补危机。

| 观察方向 | 在原文中追问 |
| --- | --- |
| 情绪牵引 | 在哪里开始在意人物，在意什么？期待、恐惧、得意或失落怎样延续、改变或断掉？ |
| 人物与相处 | 惯常反应、偏心与当下愿望怎样影响选择？对方有自己的牵挂吗，其应答是否实际改变这次经历？ |
| 场面与节奏 | 读者是在经历事情，还是只收信息与结论？哪些停顿值得停留，哪些重复令人在等它结束？ |
| 语言与叙述 | 用词、句子节奏、感知和叙述距离产生什么亲疏、声音或气氛？具体体验是否被套话、比喻或提前归纳覆盖？ |
| 余味与连续性 | 读完留下谁、什么愿望或疑问？已读后文是否改变前文的牵挂，还是反复安顿同一件事？未读后章不判断其兑现。 |

允许结论为“清楚，但并不吸引我”。可亲、愿意陪伴与迫切追读分别记，不假定自己的感受代表所有读者；不同题材、叙述方式和目标读者可有不同取舍。不把平静场面没有悬崖、较长内心或粗粝语言直接判为失败。

作者关心思考、讨论或记忆点时，首次反应保存后再按[余响诊断](meaning-and-resonance.md#保存自然反应再诊断余响)区分仍在想的问题、实际记住的经历与愿意转述的材料。没有争论或金句不自动失败，因事实不清而猜测也不算深刻；原文有潜力不能记成已经产生社会传播。

重要意见把原文位置与细节、阅读效果和产生效果的文字机制连起来；关系有疑点时回查完整场面，不只凭孤立短引。提出改法时再说明应保护的力量与修改代价，决定保留时说明为何有效，不强迫每个长处都附一个损失。说“人物鲜活”要指出其反应怎样影响这次经历，说“结尾有余味”要说明还惦记什么；“细节具体”“有张力”“更高级”本身不是依据。机制说明可以有多种合理解释，不冒充作者真实意图。意见不必统一句式，不为填满格式制造问题。

结论说明当前范围内哪些效果成立、哪里值得修订、哪些判断受背景或阅读范围限制。允许整体保留、局部修订、需要重新组织经历或尚不足判断；采用稿件不等于普遍审美认证。若办事清单挤掉了期待，或人物刚动心就被正确总结盖住，按需读[让经历值得读](reader-engagement.md)；涉及声口、语言和叙述距离，按需读[生活与叙述](life-and-voice.md)。

## 分清问题层级

人物为什么参与、关系如何变化、事件为何发生，属于构思或结构判断；场景安排和信息揭示属于叙事判断；措辞、节奏和对白属于表达判断。先处理影响较大的原因，再决定是否需要局部润色。

内容检查给出冲突双方或缺少的依据，并区分事实、人物误信、叙述策略和未确定内容。文学审读描述真实阅读效果：在哪处失去信任、感到解释过早、产生余味或看见了人物差异。审美意见承认可能有不同合理选择。

每条值得采取行动的意见应能定位原文，说明问题或长处、影响及修改方向；不要求找满数量。对有用的迟疑、粗粝和节奏变化说明为何保留。不同风格不自动等于错误。

## 判断修改是否值得

整段清楚却无吸引力时，问是否选择了值得展开的经历、切入点和信息次序。必要时比较删去或合并一场、移动揭示、换参与者或重写一个连续单元后的实际正文，而不只交两份提纲。先提出会改变读者体验的具体判断，保存原版，再读改动怎样影响前后章节。结构修改须追到人物知情、动机、承诺与后文用法；仅更新状态表不算传播完成。

作者指出内心不足时，先连续读一段完整经历，找出读者在哪处失去对人物愿望、顾虑或感受的理解，再判断需补内心、调整信息次序，还是保留原有表达。改后连读前后，检查新增文字是否带来当下体验，还是重说已经明白的结论。相同材料若承担新的关系与选择，不能只因出现多次就删除；心理增加的数量不是修好依据。

若不同场面反复完成同一价值判断，连同作品方向与交接一起检查：输入是否把尚未成立的人物解释写成了持续任务；将事实、待验证解释和后续可能性分清，再决定是否需要改正文。

有效的不舒服、不圆满和难以解释可以保留；也不能为了显得复杂给每次快乐补一个阴影。意见趋同时仍回到正文：大家是否在偏爱同一种顺畅、克制或道德姿态？指出要保护的具体力量及其成本，不因“有锋芒”就豁免动作混乱或事实冲突。

保存原稿。根据依据采纳、部分采纳或拒绝意见，由负责作品的人作出裁决；独立评阅不是投票命令。普通局部问题直接在授权范围内处理，改变作品方向的重大分歧才交作者。

先做能解决问题的适度修改；问题确在整体结构时可以重写，但不能为了显示工作量覆盖有效段落。复核已改位置及受影响的前后文、人物状态和伏笔，不为增加轮次重复整章审稿。

## 改稿比较：先辨认作用，再决定取舍

改前提出希望改变的具体阅读体验，不只说“更有文学性”。在原文中辨认已经使人投入的一两处及其作用：私人愿望、彼此回嘴、期待落空、语言亲疏，可能比一个事件更值得保护；普通局部修改不必建表。作者目标与本场作用决定取舍，不将陪伴感、追读、思考和转述便利换算成一个总分。

有必要比较时，保存完整场面的实际候选，再连读受影响前后文，不能用改稿提纲代替效果检验。重要变化说明原文怎样改了、读感有什么所得、原先哪种作用变弱或消失。损失可以是当前切入与节奏的取舍，也可能只是重写时遗漏了仍有效的愿望；不能把后者说成加强张力必须支付的代价。若能在触动位置调整注意、应答或心理而兼顾，不必先重写整场；确需改变经历组织时再重构。保留原稿、局部采用、换切入或放弃建议都可以，不强制每次生成融合稿。

不同稿各有值得保留的力量时，按[同一次经历中的融合](reader-engagement.md#把情绪牵引与生活活气写在同一次经历里)让这些作用相遇，而不只登记“各有长处”。不能剪贴好段而破坏时间、知情和声口，也不能只在结尾加心理补回。读实际形成的完整场面，检查原有投入、当场选择与配角生活是否仍成立；优点数量、拼接段数及“融合”标签都不算成功证据。作者只要求方法改进时，将可迁移的取舍写回技能，不自动替换其正文。

更顺、更短、更有动作或更便于讨论不自动更动人；内心、幽默、声音或相处变薄时不能只记收益。也不因原稿有温度而豁免事实冲突和费解句。允许原稿更好、各有收益、没有改善或尚不足判断。模型分数、评语长度、偏好票数不能证明质量；没有新的明确问题时结束该轮，不反复换题直到新方法胜出。

## 独立阅读

委派独立首次读稿时，不先给写作者自评、训练案例评价及其他评阅意见；需要理解创作意图时在首次意见保存后补充。比较与主题、记忆、转述追问需要时后置派发，不只是预先给完整问题、要求稍后作答。事实核查与首次文学反应分开记录。做方法比较时隐藏方案标签，条件允许可交换顺序；如都偏好后读版本，保留熟悉与顺序影响，不由票数裁定方法。记录实际背景暴露、模型判断与作者意见的区别。

## 质量证据与读者反馈

需要校准审美判断时，取作者实际认可、否定或有分歧的完整场面，先审读再对照反馈，查自己的解释是否只在迎合标签；不把样本褒贬、旧评语提前交给独立首读者。没有作者反馈的样本可用于模型应用核查，但不能当成文学优劣的金标准。校准后在未参与改规则的场面再应用，保留误判与分歧；不要把认可样段的句长、内心比例或速度变成通用规范。

在改法实施前说明希望改变何种体验。方法比较尽量保持输入、篇幅和修改机会相当，固定输出再审读；编辑额外修改与初次产物分开。偶然偏好、单次得分、文件完整或字数合格都不能证明某方法普遍更好。可以结论为各有收益、没有改善或仍待检验，不通过不断换题直到赢来追认优势。

真实读者可在完整单元后回答少量中性问题：哪里跳读或停下；记住了谁及什么经历；当时想继续看什么；哪个地方难以理解或与你的理解不同。先收自然反应，再问具体争议，别先讲写作意图让人配合认可。作者、其他真实读者、模型审读分开记录，未取得的反馈保持空缺；未经授权不联系外部读者。

需核查记忆或转述时，再按[潜力与实际效果](meaning-and-resonance.md#区分潜力与已发生的效果)收集对应证据。即时记忆、隔日记忆、主动交流、引用变体和实际破圈分别判断；不能由模型复述或结构检查替代真人行为。

判断分层报告：内容与接续是否成立、此单元产生何种阅读效果、方法是否有可迁移收益、长篇尺度尚缺哪些证据。前一层通过不会自动证明后一层。读者分歧可以帮助作品定位，无需抹成统一分数；决定采用稿件和证明方法优越也是两件事。
