# 单章编辑：把方法变成当章判断

用于新的章节编辑获得文脉的实际工作能力。起点是主入口、本参考、完整源章和决定当章选择的必要边界；已在上下文且未变的材料不重读。能访问Skill、继承模型配置或自称资深编辑都不等于已应用。独立首次读者不走此路线。

项目指定经验时取当前相关条目；训练JSON首次读取先只输出键名、类型和条目数，再选相关字段与指针，不先全文输出试大小。这一步在组织读取命令时就要落实，不能与全文读取并行补看规则。版本或路径不明再用[经验恢复](training-memory.md)。未指定相关经验时，可按具体问题选[随包经验](learned-practice.md)的相应段落。没有经验缺口就直接编辑，不把训练恢复与全部案例设为每岗前置；重要前文仍须完整读取。

## 先知道这章为什么值得读

连续读完源章后，辨认读者是跟谁的注意进入、这个人此刻在意什么、本章真正经历的变化，以及哪一处已经有活气。把需要修的缺陷与要保护的力量分开。新岗位可用一小段当章判断完成校准：指出一个确需修的地方和一个容易被误修的地方，以前后文说明为什么；没有缺陷就诚实说明，不硬凑错句。它是开始编辑的判断，不是每段必填表，也不是训练模型参数。

同时照顾五种彼此制约的能力：

- **成像与中文：**读者能否在需要时知道谁对什么做了什么。修主语、施受和信息次序，不把普通省略、口语量词、拟人和顺着说的短句自动判错。形式不规整与读不通是两回事。
- **心理与视角：**跟得上当下愿望、羞耻、不甘和选择，深层解释仍可未决。人物的“果然”“他不理我”可能是主观认定，不一定是作者宣布事实；不能为了知情合规把贴近人物的叙述全换成监控记录。
- **声口与节奏：**这句话是谁在说、向谁说、为什么这样说？干脆、粗粝、直写内心、长短相间均可成立。把一句顺口的椭圆式说法展开成正确操作说明，可能反而抹掉小说的声音。
- **场面与吸引力：**把篇幅留给本章值得经历的快乐、失落、交锋、相处或发现。重复确认可收，但内心不等于重复，日常不等于水，配角也不只是主角的信息接口。不统一添危险、争吵、笑话或金句。
- **取舍与连续性：**问修改让读者多经历了什么，又失去了什么；依据具体前后文，而非“更具体／更高级”。保住有效愿望、误会、笨拙与有限进展。必要因果不能靠留白掩盖，计划不能变成已发生。

准备改人物称谓或指代时，先核对发生关系的实际场面。称谓、昵称与旧名可能指向同一角色，相同称呼也可能用于不同角色；摘要、行业常识和既有模板不能替作品下结论。若所谓“澄清”依赖尚未查证的关系解释，先回原文，不能用补一段新事实消除歧义。

例如，“再磨蹭，锅里那点热乎的可不等你。”可以是一句带着亲近和催促的口语。前文已有饭菜时，不必因省略了中心词或让食物像人一样“等”便改成操作说明；若读者确实不知道锅里有什么、这又影响接下来的理解，才回查并解决歧义。例子教的是看作用和语境，不是凡有口语省略都保留。

## 真正交给新agent的内容

派发使用宿主支持的显式Skill引用或明确可解析的入口，继承当前适用模型配置，不擅自换小模型。方法与故事载荷分开：确定的Skill版本及本任务参考，另附准确源章、必要章纲和边界、作者目标与保护事实；经验和校准材料有实际需要再加。不给全部历史审稿，也不能为了省token删掉决定当章选择的前文。材料在派发前准备完成；输出截断按连续范围补读。

主编核真实候选中的上述判断，而不以“读了几个文件”验收能力。若仍将有效中文当错句或把人物磨平，针对那一处给理由，要求同章编辑比较完整场面后纠正；保留初稿和反馈，不把后补方法说成最初已会。纠正之后仍只支持这一应用，不证明以后永不失误。上下文过长时保存准确落点另开替补，不冒充同一个新岗永久继承能力。

## 完成编辑而不是完成手续

整章任务逐段照顾全部源章，真实理由成立才改；段落可以拆合，不能为了便于索引禁止有价值的重组。实际候选整章复读，报告核心修改、保护项、损失和未决。局部校对按指定范围及必要上下文处理，不扩成整章深修。

附加参考只在相应工作发生时读取：

- 本任务审查或重拟章题时取[章题参考](chapter-titles.md)；保留题名且不审题时无需加载。
- 要求段句定位、覆盖记录或准确读程核验时取[逐段参考](close-revision.md)；普通单章不必新建索引。
- 实际分章委派、批量收放或中断调度由主编取[批量参考](batch-revision.md)及需要的宿主契约；单章编辑只接收自己的任务约束与必要交付要求。作者另有明确核验要求时照办。

按本次要求核字数、源与候选版本、实际范围；可执行核验脚本而不先加载全部源码。不能以索引或台账代替读稿，也不为未启用的流程编造完成记录。

若会复述规则却仍作同类误修，按需取[完整场面的校准示例](editor-calibration.md)，再到未参与校准的新场面应用；不要每个新岗都读全部案例。

需要更细判断时按问题转入[阅读顺畅](readability.md)、[读者牵引](reader-engagement.md)、[生活与叙述](life-and-voice.md)或[修订比较](revision.md)。当章没有该问题就不加载；能力来自实际阅读和运用，不来自把参考全部勾完。
