# 人物与作品记忆

用于人物建档、写后更新、伏笔、恢复及前文修订。沿用项目现有组织；新项目先用少量可读文件，不为使用本 Skill 强制迁移资料或建设数据库。

## 人物档案

按人物重要性记录真正影响后续判断的信息：

- **行为依据：** 欲望、恐惧、价值冲突、应对习惯及来源。用有条件的倾向描述，保留相互矛盾的需求；主要转变需要经历支撑。
- **当时状态：** 身体、能力、资源、目标、人际态度，以及知道、误信和不知道的事。关系区分方向、对象和事情，不用一个好感数概括。
- **经历与变化：** 事件、人物理解、选择、代价、前后变化和正文出处。未确定动机保留解释空间，一次行为不自动证明永久性格变化。
- **原文表现：** 少量能体现声音与行动的段落。摘要提供入口，必要时读完整语境。作者已定但尚未显露的内容单列。

## 更新原则

写前保留当前依据和版本。写后只提取实际发生的变化，并检查它由何种经历支持。区分：合理发展、作者明确的新决定、草稿偏离、尚可多解。不能通过修改档案让错误草稿自动变得“正确”。

正文修订稳定后，按照作者授权的接受范围更新状态；批次内可用明确标为待审的版本接续，不要求逐项审批。核心未决问题留在短清单中。保留原先记录或变化历史，勿把一次临时反应改写成“他一直如此”。

每项重要状态能定位到正文版本、章节或场景。当前概览与历史变化分开：概览便于快速续写，历史支持倒叙、回查和改稿。写较早时点的场景时，只使用当时的知识和能力。

## 伏笔与信息揭示

记录已经埋下的线索位置、相关人物、读者可见内容、尚可解释的空间与计划中的后续意义。区分待写构想、已出现线索、后来发现可利用的细节、部分揭示、已回收和弃用。

物件出现或人物第一次注意到它，不等于其秘密已经揭晓。作者知道、角色知道、读者知道是不同状态。无需把每个细节都登记成伏笔，也不要求将所有计划强行兑现。

## 前文改动与恢复

较早事件改变时，追查受影响的人物知识、关系、资源、后续行动及线索；同步当前状态和派生摘要。不要只重写总摘要而放任旧细节继续进入后文。

交接至少让新的写作者找到：采用的正文版本、当前故事时点、人物关键状态、相关原文、未决事项和接续目标。已有材料用链接复用，避免复制整库；链接要能实际打开。

恢复时先核对交接与相关原文，有冲突就定位并处理；不能只复述摘要表示恢复成功。找不到依据的项目保持未知，不按常识补成已经发生的事实。 会话或宿主工具已更换、实时记录和历史快照矛盾时，再用[恢复参考](recovery.md)核准确批次、岗位与下一动作。

## 一个判断例子

人物原本回避求助，却为保护同伴向别人低头。这可以是有代价的一次选择。记录这件事及其后的反应，不直接写成“已克服自尊问题”，也不为维持标签而删掉选择。若人物自己说“我不在乎了”，那首先是他说过的话；它是否真实需要正文进一步支持。
