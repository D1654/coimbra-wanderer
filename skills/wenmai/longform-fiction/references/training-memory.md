# 训练经验恢复

用于找回跨会话经验、辨认当前有效修订或接续训练阅读。当前原文和相关方法已经明确时直接工作，不把本入口作为普通执笔、编辑的必经流程。独立首次读稿先走[中性首读入口](independent-reading.md)，保存首次意见后才按需要核查经验。

## 找当前条目，不展开整部历史

先定位项目指定的当前经验或简短入口；未指定且确需恢复时，可查看是否有project/training/current.json或同目录README。这是可选约定，新项目不必建数据库。项目明确指定的有效经验优先；不能为省读取而绕过作者要求，或自动用随包版本覆盖项目修订。

JSON入口首次读取，先用解析器只输出顶层键名、值类型和条目数；不用全文输出试探大小。这是发出读取命令前的选择，不能把规则与整档读取并行后再决定。随后按本任务选当前经验版本、作品入口、未决与接续位置等相关字段；字段仍大就继续选子字段或相关条目，不将整个JSON、所有历史记录或格式化全文送入上下文。没有解析器则先看文件大小、定向搜索键名并读取完整相关段落。字段名像“current”或日期较新仍不等于权威，须核项目当前决定与指向版本；路径按项目约定解析。

沿已确认指针读取本任务有关的当前经验，保留其适用条件与误用边界。只有追查冲突、反证或实际阅读进度时才回历史；相关字段也不足以判断时继续补读，不能把节流当作省略关键原文的理由。作者指定全文读取时按其要求。

没有项目相关经验时，从[随包经验](learned-practice.md)按问题选取。无需先读七条全文才能判断是否相关，可先看小目录或标题；选中条目的方法、条件、例子与边界须一起读。无论哪条路径，都另取本作品当前采用版本及必要原文，不能把经验例子导入人物正史。

恢复应找出三件事：本次交付及作品版本、相关经验的当前修订与边界、未完成阅读或创作的准确落点。需要修改现有稿件时，先读正文形成判断，再用经验核查；不要照训练示例寻找必定存在的错。经验没有当前任务需要解决的问题时，可以不用。

## 经验怎样保持有效

少量值得反复使用的判断给稳定编号；记录当前修订、适用条件、误用边界与来源。新反证出现时，明确收窄或停用旧判断，不把旧笔记悄悄改成从未错过。默认入口只推荐有效版本，历史札记按需回查。若项目入口与随包经验版本不符，定位差异，不凭较新日期把未经验证的猜想替换成熟经验。

作者要求优先；已接受正文决定故事事实。经验版本更新不能擅自改掉作品的声口、设定或过去发生的事。较旧的人物摘要与当前正文冲突时，以当前采用原文核对并修正摘要，不为了维持档案而回改成立的正文。

将原文观察、原创应用结果、作者反馈分开。读过经验的新agent可使用这种判断，但不能冒称读完来源小说。保存经验并未改变模型参数；跨会话持续性依赖文件能被找到、版本正确、实际被应用。

## 每次会话留下最少接续

训练会话记录一本书本次实读的连续范围、正在追问的问题、具体发现或反证、下一处未读位置；各岗位都能选任何一本，分工不是书目限制。章节范围按上下文与故事单元安排，保留练习和审读余量；截断输出不计读完。

写作会话只更新有变化的作品状态、采用版本和未决事项；有新的方法发现时再修经验。不要每章复制全部阅读笔记，或强制重训所有岗位。经验属于方法，人物归属、原文摘录与作者私人资料另存。

## 验证与携带

需要验证恢复时，事先冻结实际输入、经验修订与任务；让不继承训练讨论的新上下文完成陌生任务，再看正文和判断，不能只问是否记住规则。审读报告说明哪些资料实际读过、哪些未读，以及隔离来自上下文还是文件权限。输入缺失应补回或降低结论，不能补造训练经历。

新项目可携带完整Skill文件夹及当前短经验；原书不在身边仍能使用已有方法，但不能核读新的原文。原项目的阅读日志、证据档案和小说状态不自动携带。完整复制references，核验链接和版本；只复制SKILL.md会丢失训练成果。方法升级后保留可回退版本，在新场景中观察误用；一次恢复成功只能证明这一次能应用，长篇稳定性仍需在后续单元持续检查。
