# 逐段审修与定位

用于作者要求逐段逐句照顾、多章分批审修、多人交接或反复变稿，需要查明读过哪里、采用哪版时。单句修正可直接读上下文，不必使用工具或新建批次目录。

## 先连续读，再定位问题

保留原稿，按一个可完整读取的连续单元工作。先理解这段经历，再定位费解、乏味或有效之处；孤立逐句润色容易破坏节奏和人物反应。输出被截断时缩小读取范围补读，不能把发出了读取命令算成已经读完。

以阅读顺畅为目标时，结合[让读者自然读下去](readability.md)检查首次阅读的信息次序、应答和详略。全篇授权要覆盖所有指定章节；认可样段用于校准判断，不能把其句长和紧迫感变成全书统一文风。

读者在哪处失去对人物的理解，决定修改什么。关键选择突然发生，可能缺愿望或顾虑；动作难以成像，可能是对象、位置或必要前提后置；答案接不上问题，可能是说话者的意图只在提纲里。回到实际文字判断，不预先要求每段都有心理、每句短促或每章加一次自我解释。有效的留白、私心、吹牛、迟疑和闲谈仍可保留。

检查每一段不等于修改每一段。简短记录实际处理范围、重要取舍及尚未解决的问题；连续无问题的段落可合记，并留下能回查的具体观察。不用为每个普通句子写一句“合格”。

## 可选的段句工具

[revision_index.py](../scripts/revision_index.py) 只依赖 Python 标准库。它按空行分正文段、忽略独立ATX标题，将标点分出的单元编号；单元不是语言学意义的句子，省略号和对白可能需要结合上下文读。适用于正文型Markdown章节，不是表格或代码文档解析器。

```text
python -X utf8 -B path/to/longform-fiction/scripts/revision_index.py index --source chapter.md --out chapter.index.json
python -X utf8 -B path/to/longform-fiction/scripts/revision_index.py verify --source chapter.md --index chapter.index.json
python -X utf8 -B path/to/longform-fiction/scripts/revision_index.py verify --source chapter.md --index chapter.index.json --record read.json
```

索引输出必须使用尚不存在的新文件名，保留旧版以便回查。段号仅在该文件的原始字节SHA256对应版本内有效。标题、换行和BOM的改变也会换版本；在冻结前确定文件编码与换行，之后不要一边审稿一边无记录地覆盖同一路径。工具不改正文，也不替读者填写审读结论。

只有实际读完所记录的范围后，才填写该范围的人工记录。例如某一短稿确有8段，并已核完，记录可以是：

```json
{
  "source_sha256": "此处换成实际稿件的SHA256",
  "ranges": [
    {"start": 1, "end": 5, "note": "完整读过：主角原想开口讨钱，看到对方空饭碗而停住；指代与动作可接，保留。"},
    {"start": 6, "end": 8, "note": "完整读过：争执后的沉默没有重复讲理；章末约定留待后文。"}
  ]
}
```

有记录时，工具核验范围是否覆盖该版本、是否重复或缺失；没有记录只核索引完整性。通过只证明文本定位和人工声明相符，不能证明真正读懂、文学合格或心理充分。局部已读而全章未读时保留真实进度，不为通过核验补填未读段。

## 变稿与交接

跨会话保存最少的入口：当前源稿和候选路径、各自版本、实际完成范围、未决意见、接下来应读的原文。人物状态与大纲仍按[作品记忆](story-memory.md)维护；索引不能从正文自动裁定人物事实。定位、短引和摘要共同帮助回查，不能靠摘要代替受影响的正文。

改稿后重建索引，连读变动所在场面及受影响的前后文。旧记录不能换个哈希便变成新稿已审；保留它属于哪一版，另记真实复核范围。若沿用未变段的旧读程，明确列出原版与字节不变的范围，别报作新一轮全文阅读。

独立阅读先固定可识别版本，让审稿人先见正文。冻结后又有修改，逐项记录差异并复核相应范围；一次整卷首读加几处定点复核，仍只是一轮整卷首读。合订稿、阅读页和正式单章须对应最终采用版本，不用“文件已生成”替代一致性检查。

逐章分给新编辑时，先冻结源稿和必要边界，候选仅写专属目录；主编收回准确文件后再统一采用及同步，不让多个agent写同一状态表。相邻章从同一冻结起点分别修过，不等于改后能连续读；检查声口、知情、物件、伤势和章末接续的实际影响。收放及失败接续取[批量参考](batch-revision.md)，章题与全书题目重复取[章题参考](chapter-titles.md)；不能为通过台账自动填出未读范围。

交付区分：文字改了什么、实际读过什么、程序查了什么、哪些效果仍待作者或读者评价。索引降低遗漏和错版风险；整段故事是否值得写、人物是否动人，继续由真实阅读判断。
