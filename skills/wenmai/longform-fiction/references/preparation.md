# 岗位精读与校准

用于新岗位准备，或反复出现的问题需要重新学习时。已有相关材料和能力证据时直接复用，不把每章写作都变成培训。下面是上下文中的阅读、练习和经验保存，不是模型参数更新，也不证明完成了长期文学教育。

新章节编辑的有限方法载荷与当章校准取[单章编辑能力入口](chapter-editor.md)。准备的结果应出现在具体修订和保留判断里，而不只是一份“已掌握”声明；校准反馈不自动成为全书文风范本。

## 让材料回答实际问题

各岗位可轮换阅读任何适合的作品，也可读同一段比较取舍。默认每次训练会话集中一本书的一个连续单元，具体范围随上下文容量和故事落点决定；读完不等于必须写一整章练习。下一会话沿实际未读位置继续或依新问题换书，不把首轮分配固定为专业书目。

按作品目标选择少量真实原文，记录作品、版本、读到的范围及来源。古典叙事、现代文学、网络小说和其他类型可以各有所得；不靠书名印象、简介或声誉代替阅读，不把某一本书的声口设为所有小说的范式。分章研究应读相关的相邻章节，情感研究应读细节之前的关系与后果。

精读笔记保留：文字怎样产生效果，依赖哪些前提，迁移时哪里会失效。引用保持必要，受版权保护的整章不要复制进 Skill。不要命令 agent 假扮有多年履历或通读万卷；能够检查的实际判断比角色头衔有用。

研究长篇组织时，选择完整故事弧或分卷作为最终阅读单位，可分会话接续；读开端、变化、结果及必要后续后再判断。保留每次实际覆盖，读目录与读摘要不算读正文。回看开头以检验后来的重释，也寻找这部作品有效而不能直接迁移的条件。阅读覆盖与原创实践的证明范围分开，读完一卷不等于自己的长篇已稳定。

若反复出现小说化的生活套路，补入与当前作品有关的真实材料，再实践其对行动和语言的影响，见[生活与叙述](life-and-voice.md)。完整弧研究、真实材料和新题材迁移可轮换安排，不要求每次岗位准备全部执行。

## 岗位要做不同的事

- 主写在新人物、新处境中练习场面与语言，保存初稿，接受基于正文的反馈后修改。不要把名作换人名或旧失败场景换道具当迁移。
- 内容审校从正文复述动作、应答、因果与知情，同时识别有效省略；练习中保留无需修正的片段，防止只学会多解释。
- 文学审读指出投入、抽离和续读的具体缘由，比较改稿得失；能承认可理解但不好看，也能保留粗粝而有效的原句。
- 总编比较组织方式，说明取舍如何影响本章经历和相邻章节，裁决有分歧的意见；不以投票、总分或规则数量取代判断。

这些是职责，不要求四个常驻 agent。独立性有价值时另开上下文，先不给作者解释与其他评语。必要的事实依据不能为了盲读而长期隔绝。

## 保存可迁移的经验

跨会话的发现、修正与调用按[训练经验恢复](training-memory.md)维护；已有项目入口优先选择当前有效版本，没有项目记录可按需使用[随包经验](learned-practice.md)。

把有依据的发现用于另一个新任务，检查正文表现后再加入方法。保存短小的示例、适用条件和修正过的误判，保留原始判断，不把反馈倒写成从未失误。新上下文按需读取；本地存了笔记不代表以后自动具有永久记忆。

训练可以暴露过度解释、机械分章或相同声口等副作用。有此证据便收窄方法，不增加一条相反的绝对禁令。少量模型练习只支持局部观察；作者反馈与实际长期正文决定何时继续扩大。
