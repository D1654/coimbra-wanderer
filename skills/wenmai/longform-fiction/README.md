# 文脉 Wenmai

让人物的经历、故事发展与文字表达彼此贯通。调用名为`$longform-fiction`，维护者W。

当前方法版本：**0.8.0-dev.15**。提供作品构想、执笔、审读修订、跨会话恢复与长篇组织的方法。本文件用于安装、专题查找和维护；常规任务从[SKILL.md](SKILL.md)开始，无需同时读完README。经验来自有限观察与原创应用，实际文学效果由具体作品和作者阅读判断。

心理修订按一个连续经历来判断，可以补期待、顾虑，也可以删重复解释。人物对自己尚不明白，不要求读者连眼前发生什么也读不明白；具体身份和作品设定仍由项目决定。清楚、吸引力与长篇质量分别判断，不因升版承诺文学等级。

## 使用

将longform-fiction的源载荷放在目标项目的`.agents/skills/`中，并提供目标作品自己的采用正文与当前任务。保留SKILL.md、README.md、agents、完整references及可选scripts/*.py，不携带运行时编译缓存。若已有同名Skill，先保留旧版再明确更新，避免并存两个不同的当前版本。只复制SKILL.md不够。

普通单章从主入口、正文和当前相关参考开始；长篇接续遇到状态冲突时加读[恢复参考](references/recovery.md)；全书精修再按需使用[长篇尺度审读](references/whole-work-review.md)。这三类任务共享创作判断，不要求小任务启用整批台账。新编辑若反复误修，可用[完整场面校准](references/editor-calibration.md)，独立首读仍走中性入口。宿主尚未重新发现技能时，直接指定本文件夹的SKILL.md路径。

本版可直接复制完整Skill文件夹。开发仓库的完整构建入口复用同一载荷契约，可另生成带校验清单和PowerShell离线安装器的ZIP；已解包安装无需Python，直接复制目录也无需运行脚本。开发仓库的导出工具可以生成带哈希清单的独立副本：源目录scripts/__pycache__内的普通.pyc排除，未知文件和链接仍拒绝，导出副本出现额外缓存也不通过验证。通常写作不要求Python或数据库；可选定位脚本需Python 3.10及以上，仅用标准库。不自动下载书籍、发布正文或携带原项目人物档案。

## 恢复与训练

普通写作、编辑不先恢复整份训练历史。项目指定当前经验时直接取相关条目；训练JSON首次读取先仅输出键名、类型和条目数，再选当前字段与指针，不先输出全文试大小。版本或进度不明再看[训练经验恢复](references/training-memory.md)；项目无相关条目时按问题选[随包短经验](references/learned-practice.md)，连同适用条件和误用边界一起读取。独立首次读稿保存意见前不走经验路径。未读原书的agent不能继承别人的阅读经历，保存文件也不是修改模型参数。

各岗位可以读任一本书，单次训练默认集中一本的一个连续单元。经验与作品事实分开：方法可以迁移，人物的关系、秘密、版本和事件需要随各自作品恢复。过去的结论有反证时先修正版本，再作后续应用。

## 按任务读取

先选眼前问题，链接不表示所有被引用文件都要递归加载。读选中方法的完整相关部分；关键前文、源章及本次要求的复读不能因减载而省去。这里只列专题入口，不要求每次按表完成。

- [作品与人物构想](references/work-design.md)：长篇的理由、实质不同的方向、人物自述与行为。
- [让故事留下问题与记忆](references/meaning-and-resonance.md)：作者关心思考、讨论与辨识度时，从生活处境到实际场面，再区分阅读余响、转述潜力与实际传播；不增加逐章配额。
- [创作与表达](references/craft.md)：人物愿望、具体场面、语言和分章。
- [生活与叙述](references/life-and-voice.md)：真实材料的语境、叙述距离与声音差异。
- [大纲与长篇推进](references/long-arc.md)：全书、分卷、章纲及回修，阶段兑现与整体组织。
- [章题与阅读期待](references/chapter-titles.md)：正文依据、辨识度、吸引力、自然讨论及全书题名套句检查。
- [人物与作品记忆](references/story-memory.md)：变化、知情、伏笔和改稿影响。
- [审读与修订](references/revision.md)：内容校核、文学效果及前后稿比较；[文学审读分支](references/revision.md#文学效果审读)说明阅读反应、原文机制、保护项和改法代价。
- [长篇尺度审读](references/whole-work-review.md)：连续单元、完卷与整书组织，区分写作期阅读和完卷后读稿。
- [准确恢复](references/recovery.md)：会话中断、工具变化、旧快照冲突或核实际完成范围。
- [中性首读入口](references/independent-reading.md)：首次意见保存前不恢复旧判断，记录实际输入与阅读范围。
- [让读者自然读下去](references/readability.md)：以认可样段校准效果，逐章改善理解和阅读节奏，保护有效内心与各章声口。
- [让经历值得读](references/reader-engagement.md)：区分可亲、陪伴与急追，增强当场体验，减少无效重复确认，不强加危机或悬念。
- [逐段审修与定位](references/close-revision.md)：多章修订时定位、防漏、核对读程及版本；普通改句无需启用。
- [独立创作设计](references/design-collaboration.md)：人物、主线和大纲共同设计，独立提案与主编整合。
- [agent协作](references/collaboration.md)：有界委派和独立审读。
- [单章编辑能力入口](references/chapter-editor.md)：有限方法载荷、当章判断与实际候选校准，不把配置继承或文件可访问当成能力已应用。
- [完整场面校准](references/editor-calibration.md)：反复误修心理、中文、口语或设定时有针对性地使用，不是每岗必读案例。
- [有界批量审修](references/batch-revision.md)：逐章新上下文、并发槽、收回关闭、错版拒收、失败恢复与主编采用。
- [宿主生命周期记录](references/agent-lifecycle.md)：主编需要绑定关闭或回收凭据时使用，普通编辑不加载。
- [岗位精读与校准](references/preparation.md)：真实阅读、原创练习、取舍与纠偏。
- [训练经验恢复](references/training-memory.md)、[当前可迁移经验](references/learned-practice.md)：按相关问题恢复有效方法，区别于作品事实与训练历史。

## 可选工具

[段句索引脚本](scripts/revision_index.py) 提供 `index` 和 `verify`，用法及人工记录示例见[逐段参考](references/close-revision.md)。只核验当前文本与定位、覆盖声明是否一致；它不自动审稿、不生成心理描写，也不修改正文。单章可只保留必要记录，无需每次建立整卷架构。

[批量核验脚本](scripts/batch_revision.py) 检查单章编辑任务清单、未回收数量、上下文复用、文件与读程版本，以及按显式宿主契约绑定的关闭或回收凭据；只在采用逐章新上下文的批量模式使用，契约见[批量参考](references/batch-revision.md)。不会调用agent工具、填写阅读范围、决定标题或自动采用正文。关闭与回收不同，规范化证据的字段和限制见[宿主生命周期记录](references/agent-lifecycle.md)；脚本始终不声称自行看见实时库存。

## 适用限度

本版经验来自局部精读、原创练习、作者反馈和新上下文应用核查。它让已经保存的方法更容易被正确找到和使用；不保证每个模型、每次会话或每部长篇都有同样的文学效果。需要看实际正文，按新的失误修正经验；格式、哈希或恢复题通过都不是文学等级认证。

三层分别保存：通用判断随Skill携带；生活资料、人物、采用正文与审美取向由具体作品提供；阅读日志、原稿、独立评语与作者反馈属于证据。新增判断不自动成为已验证经验，模型审读也不能补填真人反馈。普通写作按当前问题读取，不要求每章完成六项流程。
