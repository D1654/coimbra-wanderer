## 应用与反证

三个互不继承编辑讨论的新上下文，先后使用原版、第一候选与最终候选处理同一份短原创样稿。三个候选均保留直接心理、误会和笨拙，仅删去相邻逐字重复句的一遍；原版在此样稿也能得到有效候选。

原版与第一候选均曾误将训练入口历史全文送入输出并截断，随后纠正。第一次候选未通过读取要求。这份反证促使最终候选把“先输出JSON结构，再选当前字段”放到实际必经的主入口。另一个全新上下文在最终候选上按此顺序读取当前经验，未输出历史正文，并完成源章与候选全文阅读。一次候选输出乱码后，另以UTF-8正常复读成功，没有将乱码当作读完。

一名独立审者核对改动、方法保留和三类路由：局部口语校对、中性首次文学阅读、没有关闭工具的多章委派。审查发现的首次读取问题与审题调用歧义，经修复后由原审者定点复核通过。这次后置复核不算第二次独立审查；生命周期情境是路由检查，没有据此宣称实际派发或回收了小说岗位。

读程轨迹来自实际编辑保存的日志与主任务核收；共享文件系统不构成权限隔离，背景项目指令也不等于零暴露。该样稿不是未见过的长篇对照集，没有新增真人文学评分。
